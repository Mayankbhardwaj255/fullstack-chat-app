# 💬 Chatty - Full Stack Real-Time Chat Application

Welcome to **Chatty**, a full-stack real-time chat application built using the **MERN stack**. This project provides a complete walkthrough of building a modern, real-time chat experience with seamless UI, real-time communication, authentication, and more.



---

## 🚀 Tech Stack

- **MongoDB** – NoSQL database for storing user and message data
- **Express.js** – Server-side framework
- **React.js** – Frontend UI
- **Node.js** – Backend runtime environment
- **Socket.io** – Real-time communication
- **Zustand** – Lightweight state management for React
- **Cloudinary** – Cloud storage for image uploads (profile & chat images)
- **DaisyUI + TailwindCSS** – Beautiful and responsive UI components

---

## ✨ Features

- 🔐 **Authentication**: User Signup and Login
- 💬 **Real-Time Messaging**: Instant communication using **Socket.io**
- 🎨 **Theme Switching**: Change app themes from settings
- 🖼 **Image Support**: Upload profile and chat images via **Cloudinary**
- 🛠 **Settings Page**: Update profile, change theme
- 📱 **Responsive UI**: Built with **DaisyUI** + **TailwindCSS**

## 🛠 Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/Mayankbhardwaj255/fullstack-chat-app
```

### 2. Backend Setup

```bash
cd backend
npm install
npm run dev
```

### 3. Frontend Setup

```bash
cd frontend
npm install
npm run dev
```

Make sure your backend server is running before you start the frontend for seamless socket connection.
